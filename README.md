# Quora-Question-Pair-Detection-using-Natural-Language-Processing


## Project Overview

Developed an NLP-based system to identify whether two Quora questions are semantically duplicate or not. The project uses deep learning approaches like Recurrent Neural Network(RNN), Long-Short-Term Memory(LSTM), Gated Recurrent Network(GRU) and Transformers for duplicate question detection.

## Models Used

* RNN
* LSTM
* GRU
* Transformer

## Workflow

Data Collection → Data Preprocessing → EDA → Feature Extraction → Model Training → Model Evaluation → Model Comparison → Best Model Selection → Streamlit Deployment.

## Results

RNN and GRU achieved the best performance among the implemented models with **85% accuracy** and **85% F1-score**.

## Evaluation Metrics

Accuracy, Precision, Recall, F1-Score, Confusion Matrix, and Training Time.

## Technologies

**Python, NLP, Pandas, NumPy, Scikit-learn, TensorFlow/Keras, RNN, LSTM, GRU, Transformers, Streamlit.**
